# CALCULATOR PROJECT

## Overview
This is a simple calculator project that is inclined towards learning rather than practical usecase.
I am deciding to make this calculator in pure C without relying on math libraries as much as possible
and I am using GTK 4.0+ for its GUI.

## Features
This calculator includes basic arithematic functions initially but I am deciding to add more advanced
functions later as this goes on.

## Project Details
This project is still ongoing and I am deciding how to implement several features
and mathematical functions. I don't know when this project would be completed as I
myself doubt that decision of completion (due its complexity and the time it takes)
